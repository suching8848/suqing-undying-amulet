# 蘇清的不死护符

[简体中文](README.md) · [English](README.en.md)

0.4.1 · Project Zomboid B42.22.2 · 单人

佩戴在胸前，或右键挂在目前背着的背包上。胸前佩戴时隐藏模型。一叠完好护符也可以直接右键挂上其中一枚。挂上和取下都显示进度条，走动、跑步或换包可以取消。动作完成后才转移道具。换包时护符随原包走，重新背起原包后恢复生效。普通项链、背部武器和原有背包挂位可以照常使用。

0.4.1 修复角色挂点组缺失时的受伤报错。护符按背包保存的挂载关系生效，缺少模型挂点时会在同步挂件时补注册。

## 重生效果

- 总生命降到 **1 HP 或以下**，或 Lua 捕获到即将发生的僵尸必死拖倒时，护符触发。胸前和背包同时装有护符时，优先使用胸前护符。
- 消耗一枚护符，在原容器留下破损护符。生命回到 **100 HP**，治疗身体部位的伤口、骨折、出血和异物。恐慌、饥饿、疲劳、中毒和 Knox 感染等状态保留。
- **3 秒内免伤并隐匿**。触发时清掉已经锁定角色的僵尸目标，尝试解除当前抓咬及待结算的拖倒。屏幕上方显示 3 → 2 → 1 倒计时，暂停时计时冻结。结束后回到角色原有的免伤和隐匿状态。

Lua 能保护的是死亡结算前仍会经过 Lua 回调的场景。待结算拖倒可尝试截住。若原生结算或其他模组同一帧直接完成死亡，Lua 可能来不及。围咬、拖倒动画、玩家能否立刻走开和外挂机制均以游戏内验收为准。

## 配方与战利品

同一个创意工坊项目提供两版。启用其中一个，切换前先关闭当前版本。两版使用相同的物品 ID，已获得的护符可继续使用。

| 模组 | 手工制作材料 |
| --- | --- |
| 蘇清的不死护符（默认配方） | 一条符合配方的宝石、琥珀或珍珠项链、0.5 L 纯动物血液。需要钳子，保留钳子和装血容器。 |
| 蘇清的不死护符（简单配方） | 一块石块和一条碎布条。 |

军营的军用箱子、首饰店的展示柜和后仓储物柜都有机会刷出完好护符。首饰店的抽取权重是军用箱子的两倍，实际数量受沙盒战利品稀有度影响。掉落在容器首次生成战利品时结算。

完好护符的调试物品 ID 为 `SuQingUndyingAmulet.UndyingAmulet`，破损件为 `SuQingUndyingAmulet.BrokenUndyingAmulet`。

## 隔离档验收

1. 用交付目录下的隔离启动入口进入原测试档或新建测试人物。需要调试菜单时使用调试入口，常规玩法使用无调试入口。入口使用独立存档和设置，并沿用本机 PZO。主菜单模组名单应启用其中一个配方版本。
2. 打开调试菜单的「物品列表」，搜 **蘇清的不死护符** 或模块 **SuQingUndyingAmulet**，生成两枚。先试胸前佩戴，再把另一枚从物品栏右键挂到正在背的包上。换一个包后应失效，重新背回原包后应恢复。背包方式可以用取下菜单解除。
3. 用调试菜单的角色身体状态面板制造伤势，将总生命调到 **1**。确认只破碎一枚、生命恢复到 100、伤口清除，恐慌等非伤口状态保留，并出现激活提示。保护结束应有短提示。
4. 另起测试人物，在启用沙盒群体拖倒的场景用一小群僵尸围住自己。依次看高血量拖倒会不会触发、触发后能不能立刻走开、3 秒内僵尸会不会再锁定或控制你、结束后僵尸能不能重新发现角色。记录测试时是否已经倒地，以及激活提示是否出现。
5. 验证一次保存并读回。破损件应保留，重新装备原包时完好的外挂品应恢复，加载之后不应继续继承本轮的临时保护。

完好和破损护符有各自的图标及落地模型。胸前佩戴时隐藏，挂在背包上时显示短扣挂件。

## Viewpoint 0.1.7

使用随附的 Viewpoint 隔离入口。第一人称检查手持、地面模型、拾取和物品栏的挂取进度条。切到第三人称确认胸前佩戴时隐藏，再查看背包挂件。用小背包、登山背包和军用背包分别核对站立、转身、跑步时的短扣位置，优先记录悬空、明显穿模或镜头遮挡。
